# העלאת "רכב בקליק" ל-Google Play — מדריך שלב אחר שלב

הכול כאן מוכן. נשארו שלבים שדורשים חשבון וגישה אישית שלך.

---

## שלב 1 — חשבון מפתח (פעם אחת, 25$)

1. להיכנס ל-https://play.google.com/console ולהירשם.
2. **מומלץ להירשם כארגון (חברה) ולא כאדם פרטי** — לחשבונות אישיים חדשים
   גוגל דורשת תקופת בדיקה עם 12 בודקים לפני פרסום ציבורי. לארגון נדרשים
   מסמכי חברה ומספר D-U-N-S.
3. אימות הפרטים אצל גוגל לוקח בין יום לכמה ימים. **כדאי להתחיל בזה מוקדם.**

## שלב 2 — יצירת קובץ האפליקציה

האפליקציה היא מעטפת סביב האתר החי, כך ששינויים באתר מגיעים למשתמשים
מיד — בלי גרסה חדשה בחנות.

1. להיכנס ל-https://www.pwabuilder.com
2. להזין את הכתובת: `https://rechev-beklik.onrender.com`
3. ללחוץ **Package for stores** ← **Android** ← **Generate**
4. להוריד את הקובץ. בתוכו יש:
   - `app-release-bundle.aab` — הקובץ שמעלים לחנות
   - `assetlinks.json` — קובץ אימות בעלות
   - `signing.keystore` + סיסמאות — **לשמור בכספת. בלי זה אי אפשר לעדכן את האפליקציה לעולם.**

## שלב 3 — אימות הבעלות על האתר (חשוב!)

בלי זה האפליקציה תיפתח עם שורת כתובת של דפדפן במקום מסך מלא.

1. לפתוח את `assetlinks.json` שהתקבל מ-PWABuilder ולהעתיק את תוכנו.
2. להחליף בו את התוכן של `public/assetlinks.json` בפרויקט.
3. לבקש ממני לפרוס — או להריץ:
   ```
   git add public/assetlinks.json && git commit -m "assetlinks" && git push
   ```
4. לוודא שהקובץ נגיש: https://rechev-beklik.onrender.com/.well-known/assetlinks.json

## שלב 4 — מילוי פרטי האפליקציה בחנות

כל הטקסטים מוכנים בקובץ `listing.md`:
- שם, תיאור קצר, תיאור מלא
- קטגוריה ותגיות
- כתובת מדיניות הפרטיות
- תשובות לטופס בטיחות הנתונים ולדירוג התוכן

**קבצים להעלאה:**
| מה | קובץ |
|---|---|
| אייקון (512×512) | `public/icon-512.png` |
| באנר ראשי (1024×500) | `store/feature-graphic.png` |
| צילומי מסך | `store/screenshots/` — מומלץ 03, 04, 02, 06 |

## שלב 5 — פרסום

1. להעלות את קובץ ה-`.aab`
2. לבחור מדינות הפצה (ישראל)
3. לשלוח לבדיקה — האישור לוקח בדרך כלל בין שעות ליום-יומיים
